# 🤖 Liya AI Assistant

Liya is an intelligent desktop AI assistant built to feel like a real personal assistant rather than just another chatbot.

Unlike traditional AI chat applications, Liya combines conversational AI, desktop automation, project memory, browser integration, and vision capabilities into one unified assistant.

> ⚠️ Liya is currently under active development. New features and improvements are added regularly.

---

# ✨ Features

## 🧠 Intelligent Conversation

- Natural voice conversations
- Context-aware responses
- Persistent conversation memory
- Project-specific memory
- Human-like emotional responses
- Long-term user preferences

---

## 💻 Desktop Control

Liya can perform desktop tasks including:

- Open installed applications
- Create files and folders
- Rename files
- Delete files (with confirmation)
- Read files
- Write files
- Clipboard access
- Launch websites
- Execute safe desktop actions
- System utility access

Every action is verified before reporting success.

---

## 🌐 Smart Browser Integration

- Open websites
- Open search queries
- Intelligent browser control
- Automatic keyword optimization
- Fast browser navigation

---

## 👀 Vision Mode

Liya can analyze your shared screen.

Examples:

- Explain code
- Read text
- Describe UI
- Identify errors
- Help with debugging

---

## 📂 Project Memory

Liya remembers your projects.

She stores:

- Project name
- Completed features
- Pending tasks
- Bugs
- Technical decisions
- Development progress

Project memory survives restarts.

---

## 🧩 Workspace Awareness

Liya understands your workspace.

Examples:

- Current project
- Active application
- Open folders
- Coding sessions
- Development workflow

---

## 🛠 Reliability System

Every desktop action follows:

Execute

↓

Verify

↓

Retry

↓

Alternative Method

↓

Report

Liya never assumes success.

---

## 📈 Planned Features

- Multi-agent architecture
- Vision improvements
- Local AI models
- Plugin ecosystem
- Mobile companion
- Smart scheduling
- Autonomous task planning
- Offline reasoning
- Self-healing modules

# 📦 Installation

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/liya-ai-assistant.git
```

```bash
cd liya-ai-assistant
```

---

## 2. Install dependencies

```bash
npm install
```

---

## 3. Configure Environment Variables

Create a `.env` file in the project root.

Example:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Add any other required environment variables used by your project.

---

## 4. Start the development server

```bash
npm run dev
```

or

```bash
npm start
```

depending on your project configuration.

---

## 5. Open the application

Visit:

```
http://localhost:3000
```

or the port displayed in your terminal.
